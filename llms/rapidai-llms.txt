# RapidAI

> RapidAI (legal entity iSchemaView, Inc., San Mateo, California) builds a deep clinical AI
> platform for medical imaging. Its FDA-cleared Rapid product family analyzes non-contrast CT,
> CT angiography, CT perfusion and MRI studies to triage ischemic stroke, hemorrhagic stroke,
> aneurysm, pulmonary embolism and aortic disease. The Rapid Enterprise Platform integrates with
> hospital PACS, RIS, EHR and radiology worklist systems over HL7, FHIR and DICOM.

Generated by the API Evangelist enrichment pipeline on 2026-08-02 from the public RapidAI web
surface. RapidAI does not publish an llms.txt of its own (https://www.rapidai.com/llms.txt → 404).

## API posture (read this first)

RapidAI has an API, but it is **not public**. There is no developer portal, no API reference,
no OpenAPI/Swagger definition, no SDKs, no CLI, no sandbox, no MCP server and no A2A agent card.

- The **Rapid Technology Partner API** lets technology partners integrate Rapid results into
  their own products. Access is granted through the Rapid Technology Partner Program, not by
  self-service sign-up: https://www.rapidai.com/partners
- Hospital-side integration is documented as "Standard (HL7, FHIR, DICOM) and custom APIs"
  against PACS, RIS, EHR and radiology worklist systems:
  https://www.rapidai.com/platform/workflow-integration
- The production API host observed in RapidAI's own Rapid Web App bundle is
  `https://api.us.rapid-sys.com` (URI-path version `v4`, AWS API Gateway). Anonymous calls
  return HTTP 403 `{"message":"Missing Authentication Token"}`.
- EU traffic is served from `https://api.eu-west-3.core.prod.rapid-sys.com`.

Do not attempt to construct RapidAI API calls from this document. No public request/response
contract exists; contact the partner program.
